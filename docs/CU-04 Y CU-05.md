# Casos de Uso: Calificaciones

## CU-04 — Consultar Calificaciones

| Campo | Descripción |
|---|---|
| **Identificador** | CU-04 |
| **Nombre** | Consultar Calificaciones |
| **Actores** | Alumno |
| **Disparador** | El alumno inicia sesión en el sistema y selecciona la opción de consultar sus calificaciones. |
| **Descripción** | El alumno consulta sus calificaciones parciales y finales de las materias en las que está inscrito durante el periodo actual, así como calificaciones de periodos anteriores. |
| **Precondiciones** | 1. El alumno ha iniciado sesión en el sistema.<br>2. El alumno está inscrito en al menos una materia.<br>3. Existen calificaciones registradas por los profesores. |
| **Postcondiciones** | 1. El alumno visualiza sus calificaciones organizadas por materia y periodo.<br>2. Se registra la consulta para estadísticas de uso. |
| **Frecuencia de uso** | Alta, específicamente en periodos de evaluación |
| **Prioridad** | Media |
| **Flujo Normal** | 1. El alumno inicia sesión en el sistema con sus credenciales.<br>2. El alumno navega a la sección “Consultar Calificaciones”.<br>3. El sistema identifica al alumno y consulta las materias inscritas en el periodo actual.<br>4. El sistema recupera las calificaciones parciales y finales registradas para cada materia.<br>5. El sistema muestra las calificaciones organizadas por materia del periodo actual.<br>6. El alumno visualiza sus calificaciones en pantalla.<br>7. El sistema registra la consulta en el log para estadísticas de uso. |
| **Flujos Alternativos** | **Consultar calificaciones de periodos anteriores:**<br>1. En el paso 5, el alumno selecciona “Ver periodos anteriores”.<br>2. El sistema muestra una lista de periodos anteriores disponibles.<br>3. El alumno selecciona el periodo que desea consultar.<br>4. El sistema recupera y muestra las calificaciones de ese periodo.<br>5. Se registra la consulta en el log.<br><br>**Filtrar por materia específica:**<br>1. En el paso 5, el alumno utiliza un filtro para buscar una materia específica.<br>2. El sistema muestra únicamente las calificaciones de la materia seleccionada. |
| **Excepciones** | **No hay calificaciones registradas aún:** En el paso 4, si los profesores no han registrado calificaciones, el sistema muestra “Aún no se han registrado calificaciones para este periodo”.<br>**El alumno no está inscrito en ninguna materia:** En el paso 3, si el alumno no tiene materias inscritas, se muestra un mensaje indicando la situación.<br>**Error de conexión con la base de datos:** En el paso 4, si ocurre un fallo, el sistema muestra un mensaje de error y sugiere reintentar. |
| **Reglas de Negocio** | 1. Cada alumno solo puede consultar sus propias calificaciones.<br>2. Las calificaciones mostradas deben corresponder exactamente a las registradas por los profesores.<br>3. Las calificaciones de periodos anteriores deben mantenerse accesibles.<br>4. Se debe registrar cada consulta para fines estadísticos y de auditoría. |
| **Requerimientos Especiales** | 1. La consulta debe cargar en menos de 5 segundos.<br>2. La interfaz debe presentar las calificaciones de forma clara, en formato de tabla.<br>3. La vista debe ser responsiva para dispositivos móviles.<br>4. Se podría considerar la opción de exportar las calificaciones en PDF. |
| **Suposiciones** | 1. Se asume que los profesores registran las calificaciones de forma previa.<br>2. Se asume que el sistema organiza las calificaciones por alumno, materia y periodo.<br>3. Se asume que la información de inscripción del alumno ya está cargada en el sistema.<br>4. Se asume que “calificaciones parciales” se refiere a evaluaciones intermedias y “finales” a la calificación definitiva.<br>5. Se asume que la funcionalidad de exportar calificaciones (PDF) no es un requerimiento actual. |

## 1.5. CU-05 — Registrar Calificaciones

| Campo | Descripción |
|---|---|
| **Identificador** | CU-05 |
| **Nombre** | Registrar Calificaciones |
| **Actores** | Profesor |
| **Disparador** | El profesor inicia sesión en el sistema y selecciona la opción de registrar calificaciones para uno de sus grupos asignados durante el periodo de captura abierto. |
| **Descripción** | El profesor registra las calificaciones de evaluaciones (exámenes, tareas, proyectos) para los alumnos de sus grupos asignados. |
| **Precondiciones** | 1. El profesor ha iniciado sesión en el sistema.<br>2. El profesor tiene grupos asignados en el periodo actual.<br>3. El periodo de captura de calificaciones está abierto. |
| **Postcondiciones** | 1. Las calificaciones quedan registradas en el sistema.<br>2. Los alumnos reciben notificación de nuevas calificaciones.<br>3. Se actualiza el promedio del alumno en la materia.<br>4. Se registra la acción en el log de auditoría. |
| **Frecuencia de uso** | Alta, específicamente en periodos de evaluación |
| **Prioridad** | Alta |
| **Flujo Normal** | 1. El profesor inicia sesión en el sistema con sus credenciales.<br>2. El profesor navega a la sección “Registrar Calificaciones”.<br>3. El sistema muestra la lista de grupos asignados al profesor.<br>4. El profesor selecciona el grupo para el cual desea registrar calificaciones.<br>5. El sistema muestra la lista de alumnos inscritos en ese grupo.<br>6. El profesor selecciona el tipo de evaluación a calificar.<br>7. El profesor ingresa la calificación correspondiente para cada alumno.<br>8. El profesor confirma el registro de las calificaciones.<br>9. El sistema valida que las calificaciones estén dentro del rango permitido.<br>10. El sistema almacena las calificaciones en la base de datos.<br>11. El sistema actualiza el promedio de cada alumno en la materia.<br>12. El sistema envía una notificación a los alumnos informando nuevas calificaciones.<br>13. El sistema registra la acción en el log de auditoría.<br>14. El sistema muestra un mensaje de confirmación al profesor. |
| **Flujos Alternativos** | **Registrar calificaciones parcialmente:**<br>1. En el paso 7, el profesor ingresa calificaciones solo para algunos alumnos.<br>2. El profesor confirma el registro parcial.<br>3. El sistema almacena únicamente las calificaciones ingresadas.<br>4. El sistema notifica solo a los alumnos cuyas calificaciones fueron registradas.<br>5. El profesor puede completar las calificaciones faltantes posteriormente.<br><br>**Modificar una calificación ya registrada:**<br>1. En el paso 5, el sistema muestra calificaciones ya registradas para la evaluación.<br>2. El profesor modifica la calificación de uno o más alumnos.<br>3. El profesor confirma los cambios.<br>4. El sistema actualiza las calificaciones, recalcula promedios y registra la modificación.<br>5. Los alumnos afectados reciben notificación de la actualización. |
| **Excepciones** | **Periodo de captura cerrado:** Si el periodo de captura ya no está abierto, se muestra un mensaje indicando que no es posible registrar calificaciones.<br>**Calificación fuera del rango permitido:** En el paso 9, si alguna calificación no está dentro del rango válido, el sistema resalta el campo con error e indica el rango permitido.<br>**Grupo sin alumnos inscritos:** En el paso 5, si el grupo no tiene alumnos inscritos, el sistema muestra un mensaje.<br>**Error al guardar en la base de datos:** En el paso 10, si ocurre un fallo técnico, el sistema muestra un mensaje de error y sugiere reintentar.<br>**Fallo en el envío de notificaciones:** En el paso 12, las calificaciones se mantienen registradas y el fallo se registra en el log. |
| **Reglas de Negocio** | 1. Solo los profesores pueden registrar calificaciones, y únicamente para sus grupos asignados.<br>2. Las calificaciones solo se pueden capturar mientras el periodo de captura esté abierto.<br>3. Las calificaciones deben estar dentro del rango válido definido por la institución.<br>4. Toda captura y modificación debe quedar registrada en el log de auditoría.<br>5. El sistema debe recalcular automáticamente el promedio del alumno.<br>6. Los alumnos deben ser notificados cuando se registren o modifiquen calificaciones. |
| **Requerimientos Especiales** | 1. Interfaz de captura rápida con navegación por tabulador.<br>2. Soporte para captura concurrente de múltiples profesores.<br>3. Tiempo de guardado menor a 3 segundos.<br>4. Mecanismo de autoguardado o borrador.<br>5. Notificaciones asíncronas. |
| **Suposiciones** | 1. Se asume que la asignación de grupos a profesores ya fue realizada.<br>2. Se asume que el periodo de captura es gestionado por la administración académica.<br>3. Se asume que la lista de alumnos inscritos está actualizada.<br>4. Se asume que el sistema de notificaciones ya está implementado.<br>5. Se asume que el cálculo del promedio se basa en las calificaciones registradas. |
