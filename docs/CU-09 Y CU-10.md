# Casos de Uso: Asignaciones y Tareas Pendientes

## 1.9. CU-09 — Crear y Publicar Asignación

| Campo                         | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Identificador**             | CU-09                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Nombre**                    | Crear y Publicar Asignación                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Actores**                   | Profesor                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Disparador**                | El profesor inicia sesión en el sistema y decide crear una nueva asignación académica para uno de sus grupos asignados.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Descripción**               | El profesor crea una nueva asignación académica (tarea, proyecto, ensayo, práctica) para un grupo específico, definiendo instrucciones, fecha de entrega, rúbrica de evaluación y materiales de apoyo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Precondiciones**            | 1. El profesor ha iniciado sesión.<br>2. El profesor tiene grupos asignados.<br>3. El periodo académico está activo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Postcondiciones**           | 1. La asignación queda publicada y visible para los alumnos del grupo.<br>2. Los alumnos reciben notificación de nueva tarea.<br>3. Se crea el registro de entrega pendiente para cada alumno.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Frecuencia de uso**         | Alta                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Prioridad**                 | Alta                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Flujo Normal**              | 1. El profesor inicia sesión en el sistema con sus credenciales.<br>2. El profesor navega a “Crear Asignación”.<br>3. El sistema muestra la lista de grupos asignados al profesor.<br>4. El profesor selecciona el grupo.<br>5. El sistema muestra el formulario de creación de asignación.<br>6. El profesor ingresa el tipo de asignación (tarea, proyecto, ensayo, práctica).<br>7. El profesor redacta las instrucciones de la asignación.<br>8. El profesor establece la fecha y hora límite de entrega.<br>9. El profesor adjunta la rúbrica de evaluación (si aplica).<br>10. El profesor adjunta materiales de apoyo si los hay.<br>11. El profesor revisa la información y confirma la publicación.<br>12. El sistema valida que los campos obligatorios estén completos.<br>13. El sistema almacena la asignación y la publica para el grupo.<br>14. El sistema crea un registro de entrega pendiente para cada alumno.<br>15. El sistema envía una notificación a los alumnos del grupo.<br>16. El sistema muestra un mensaje de confirmación al profesor. |
| **Flujos Alternativos**       | **Guardar asignación como borrador:**<br>1. En el paso 11, el profesor selecciona “Guardar como borrador”.<br>2. El sistema almacena la asignación con estatus de borrador.<br>3. La asignación no es visible para los alumnos ni se envían notificaciones.<br>4. El profesor puede regresar a editar y publicar el borrador.<br><br>**Crear asignación sin rúbrica ni materiales:**<br>1. En los pasos 9 y 10, el profesor no adjunta rúbrica ni materiales.<br>2. El flujo continúa normalmente (campos opcionales).<br><br>**Publicar asignación para múltiples grupos:**<br>1. En el paso 4, el profesor selecciona más de un grupo.<br>2. El sistema replica la asignación para cada grupo seleccionado.<br>3. Se crean registros de entrega para todos los grupos.<br>4. Se envían notificaciones a los alumnos de todos los grupos.                                                                                                                                                                                                                            |
| **Excepciones**               | **Campos obligatorios incompletos:** En el paso 12, si faltan campos obligatorios, el sistema resalta los faltantes.<br>**Fecha de entrega inválida:** Si la fecha es anterior a la actual o fuera del periodo, el sistema muestra un error.<br>**Error al adjuntar archivos:** Si un archivo no puede cargarse, el sistema muestra el problema.<br>**Error al guardar en la base de datos:** Si ocurre un fallo técnico, el sistema muestra un mensaje de error.<br>**Fallo en el envío de notificaciones:** La asignación se mantiene publicada y el fallo se registra en el log.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Reglas de Negocio**         | 1. Solo los profesores pueden crear asignaciones para sus grupos asignados.<br>2. Toda asignación debe tener: título, instrucciones y fecha de entrega.<br>3. La fecha de entrega debe ser futura dentro del periodo activo.<br>4. Se debe crear automáticamente un registro de entrega pendiente por alumno.<br>5. Los alumnos deben ser notificados al publicar.<br>6. La rúbrica y materiales de apoyo son opcionales.<br>7. Un borrador no es visible para los alumnos.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Requerimientos Especiales** | 1. Soporte de carga de archivos en formatos comunes (máximo 25 MB por archivo).<br>2. Editor de texto enriquecido para instrucciones.<br>3. Autoguardado o borrador para prevenir pérdida de datos.<br>4. Notificaciones asíncronas.<br>5. Interfaz responsiva.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Suposiciones**              | 1. Se asume que la asignación de grupos a profesores ya fue realizada.<br>2. Se asume que la lista de alumnos inscritos está actualizada y sincronizada.<br>3. Se asume que el sistema de notificaciones está operativo.<br>4. Se asume que el profesor define la rúbrica de forma manual.<br>5. Se asume que la opción de publicar para múltiples grupos simultáneamente es deseable pero no obligatoria en la primera versión.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## 1.10. CU-10 — Visualizar Tareas Pendientes

| Campo                         | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Identificador**             | CU-10                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Nombre**                    | Visualizar Tareas Pendientes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Actores**                   | Alumno                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Disparador**                | El alumno inicia sesión en el sistema y accede a la sección de tareas pendientes para revisar sus asignaciones.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Descripción**               | El alumno consulta la lista de tareas y asignaciones pendientes de todas sus materias, organizadas por fecha de entrega, con indicadores visuales de urgencia y estado.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Precondiciones**            | 1. El usuario ha iniciado sesión.<br>2. El alumno está inscrito en materias con tareas asignadas.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Postcondiciones**           | 1. El alumno visualiza todas sus tareas pendientes.<br>2. El alumno puede filtrar y ordenar las tareas según sus necesidades.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Frecuencia de uso**         | Muy Alta, acceso diario                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Prioridad**                 | Alta                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Flujo Normal**              | 1. El alumno inicia sesión en el sistema con sus credenciales.<br>2. El alumno navega a la sección “Tareas Pendientes” o la selecciona desde el menú principal/dashboard.<br>3. El sistema identifica al alumno y consulta en la base de datos todas las asignaciones pendientes de las materias en las que está inscrito.<br>4. El sistema organiza las tareas por fecha de entrega (de la más próxima a la más lejana).<br>5. El sistema asigna indicadores visuales de urgencia a cada tarea (rojo = próxima a vencer, amarillo = próximos días, verde = aún hay tiempo).<br>6. El sistema asigna indicadores de estado a cada tarea (pendiente, en progreso, entregada, vencida).<br>7. El sistema muestra la lista de tareas pendientes con: nombre de la tarea, materia, fecha de entrega, indicador de urgencia e indicador de estado.<br>8. El alumno visualiza sus tareas pendientes y puede identificar cuáles requieren atención inmediata. |
| **Flujos Alternativos**       | **Filtrar tareas por materia:**<br>1. En el paso 8, el alumno selecciona un filtro para ver únicamente las tareas de una materia específica.<br>2. El sistema actualiza la lista mostrando solo las tareas de la materia seleccionada.<br><br>**Ordenar tareas por criterio diferente:**<br>1. En el paso 8, el alumno cambia el criterio de ordenamiento (por materia, por estado, por tipo de asignación).<br>2. El sistema reorganiza la lista según el criterio seleccionado.<br><br>**Acceder a los detalles de una tarea:**<br>1. En el paso 8, el alumno selecciona una tarea específica de la lista.<br>2. El sistema muestra los detalles completos de la asignación (instrucciones, rúbrica, materiales de apoyo, fecha límite).<br>3. Desde ahí, el alumno puede iniciar el proceso de entrega si lo desea.                                                                                                                                 |
| **Excepciones**               | **No hay tareas pendientes:** En el paso 3, si no hay asignaciones pendientes, se muestra “No tienes tareas pendientes en este momento. ¡Estás al día!”<br>**El alumno no tiene materias inscritas:** En el paso 3, si el alumno no está inscrito en ninguna materia, el sistema muestra un mensaje indicando la situación.<br>**Error al cargar las tareas:** Si ocurre un fallo técnico, el sistema muestra un mensaje de error y sugiere reintentar.<br>**Tareas con fechas vencidas:** En el paso 6, si existen tareas cuya fecha ya pasó y el alumno no las entregó, el sistema las muestra con indicador de “Vencida” pero no las oculta.                                                                                                                                                                                                                                                                                                        |
| **Reglas de Negocio**         | 1. Solo se muestran las tareas de las materias en las que el alumno está inscrito.<br>2. Las tareas deben organizarse por defecto por fecha de entrega (más próxima primero).<br>3. Los indicadores de urgencia deben calcularse automáticamente según la proximidad de la fecha de entrega.<br>4. Las tareas vencidas no entregadas deben seguir siendo visibles.<br>5. El estado de cada tarea debe actualizarse en tiempo real.<br>6. Cada alumno solo visualiza sus propias tareas pendientes.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Requerimientos Especiales** | 1. Indicadores visuales de urgencia claros e intuitivos (código de colores).<br>2. Carga de la lista menor a 3 segundos.<br>3. Interfaz completamente responsiva, optimizada para dispositivos móviles.<br>4. Filtrado y ordenamiento dinámico sin recargar la página.<br>5. Contador visible de tareas pendientes en el menú o dashboard.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Suposiciones**              | 1. Se asume que las tareas fueron creadas y publicadas previamente por los profesores.<br>2. Se asume que el sistema tiene definidos los criterios para los indicadores de urgencia.<br>3. Se asume que el estado de cada tarea se actualiza automáticamente al realizar una entrega.<br>4. Se asume que la lista incluye tareas de todas las materias inscritas.<br>5. Se asume que las tareas vencidas permanecen visibles por un periodo razonable.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
