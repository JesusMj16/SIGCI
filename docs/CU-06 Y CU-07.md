# Casos de Uso: Horarios e Historial Académico

## 1.6. CU-06 — Consultar Horario de Clases

| Campo                         | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Identificador**             | CU-06                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Nombre**                    | Consultar Horario de Clases                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Actores**                   | Alumno, Profesor                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Disparador**                | El usuario (alumno o profesor) inicia sesión en el sistema y selecciona la opción de consultar su horario de clases.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Descripción**               | El usuario consulta su horario de clases del periodo actual, visualizando materias, horarios, aulas y profesores/grupos según corresponda a su rol.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Precondiciones**            | 1. El usuario ha iniciado sesión.<br>2. El usuario tiene materias inscritas o grupos asignados.<br>3. El periodo académico está activo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Postcondiciones**           | 1. El usuario visualiza su horario completo.<br>2. Opcionalmente, puede agregar el horario a su calendario personal.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Frecuencia de uso**         | Alta. Consulta diaria                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Prioridad**                 | Alta                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Flujo Normal**              | 1. El usuario inicia sesión en el sistema con sus credenciales.<br>2. El usuario navega a la sección “Consultar Horario de Clases”.<br>3. El sistema identifica el rol del usuario (alumno o profesor).<br>4. Si es alumno: el sistema consulta las materias inscritas y recupera horarios, aulas y profesores. Si es profesor: el sistema consulta los grupos asignados y recupera horarios, aulas y materias.<br>5. El sistema muestra el horario en formato de tabla semanal.<br>6. El usuario visualiza su horario completo.<br>7. El usuario puede opcionalmente agregar el horario a su calendario personal. |
| **Flujos Alternativos**       | **Agregar horario al calendario personal:**<br>1. En el paso 7, el usuario selecciona “Agregar a calendario”.<br>2. El sistema genera un archivo .ics compatible.<br>3. El usuario descarga o importa el archivo en su aplicación de calendario.<br>4. Los eventos de clase quedan registrados en el calendario personal.<br><br>**Consultar horario de un día específico:**<br>1. En el paso 5, el usuario selecciona un día específico.<br>2. El sistema muestra únicamente las clases de ese día.                                                                                                               |
| **Excepciones**               | **No hay materias inscritas ni grupos asignados:** En el paso 4, se muestra un mensaje indicando “No se encontraron materias/grupos para el periodo actual.”<br>**Periodo académico inactivo:** En el paso 4, se muestra un mensaje y se ofrece consultar el último periodo registrado.<br>**Error al cargar el horario:** Si ocurre un fallo técnico, el sistema muestra un mensaje de error y sugiere reintentar.<br>**Fallo al generar archivo de calendario:** Si el archivo .ics no puede generarse, se muestra un mensaje de error.                                                                          |
| **Reglas de Negocio**         | 1. Cada usuario solo puede visualizar su propio horario.<br>2. El horario mostrado debe corresponder al periodo académico activo.<br>3. La información debe estar sincronizada con la administración académica.<br>4. La opción de agregar al calendario es complementaria y no obligatoria.                                                                                                                                                                                                                                                                                                                       |
| **Requerimientos Especiales** | 1. Vista clara en formato de tabla semanal.<br>2. Interfaz completamente responsiva.<br>3. Tiempo de carga no debe exceder los 3 segundos.<br>4. Formato .ics para exportación a calendario.<br>5. Diferenciación visual por colores para las materias.                                                                                                                                                                                                                                                                                                                                                            |
| **Suposiciones**              | 1. Se asume que la asignación de horarios y aulas ya fue realizada.<br>2. Se asume que el sistema tiene la información del periodo académico.<br>3. Se asume que el usuario accede desde un dispositivo con navegador web.<br>4. Se asume que los cambios de horario se reflejan automáticamente.<br>5. Se asume que “calendario personal” se refiere a aplicaciones externas.                                                                                                                                                                                                                                     |

## 1.7. CU-07 — Consultar Historial Académico

| Campo                         | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Identificador**             | CU-07                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Nombre**                    | Consultar Historial Académico                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Actores**                   | Alumno                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Disparador**                | El alumno inicia sesión en el sistema y selecciona la opción de consultar su historial académico.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Descripción**               | El alumno consulta su historial académico completo, incluyendo todas las materias cursadas, calificaciones obtenidas, créditos acumulados y avance curricular.                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Precondiciones**            | 1. El usuario ha iniciado sesión.<br>2. El usuario tiene al menos un semestre cursado.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Postcondiciones**           | 1. El alumno visualiza su historial académico completo.<br>2. Puede identificar su avance en el plan de estudios.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Frecuencia de uso**         | Media                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Prioridad**                 | Media                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Flujo Normal**              | 1. El alumno inicia sesión en el sistema con sus credenciales.<br>2. El alumno navega a la sección “Consultar Historial Académico”.<br>3. El sistema identifica al alumno y consulta todas las materias cursadas.<br>4. El sistema recupera calificaciones obtenidas, créditos y estatus (aprobada, reprobada, en curso).<br>5. El sistema calcula los créditos acumulados y el porcentaje de avance curricular.<br>6. El sistema muestra el historial organizado por semestre/periodo.<br>7. El alumno visualiza su historial completo e identifica su avance.      |
| **Flujos Alternativos**       | **Filtrar historial por semestre específico:**<br>1. En el paso 6, el alumno selecciona un semestre específico.<br>2. El sistema filtra y muestra solo las materias de ese semestre.<br><br>**Descargar historial académico:**<br>1. En el paso 7, el alumno selecciona “Descargar Historial”.<br>2. El sistema genera un documento PDF con el historial completo.<br>3. El alumno descarga el archivo.                                                                                                                                                              |
| **Excepciones**               | **Sin historial registrado:** En el paso 3, si no hay materias cursadas, se muestra “Aún no cuentas con historial académico registrado.”<br>**Datos incompletos:** En el paso 4, si algunas materias no tienen calificación, se muestran con indicador de “Calificación pendiente”.<br>**Error al consultar la base de datos:** Si ocurre un fallo técnico, el sistema muestra un mensaje de error.<br>**Plan de estudios no encontrado:** En el paso 5, si no se puede asociar al alumno con un plan de estudios, se muestra el historial sin porcentaje de avance. |
| **Reglas de Negocio**         | 1. Cada alumno solo puede consultar su propio historial.<br>2. El historial debe incluir todas las materias cursadas, incluyendo las reprobadas.<br>3. Los créditos acumulados deben calcularse solo con materias aprobadas.<br>4. El avance curricular debe calcularse respecto al total de créditos del plan de estudios.<br>5. La información debe coincidir con los registros oficiales.                                                                                                                                                                         |
| **Requerimientos Especiales** | 1. Presentación organizada por semestre en formato de tabla.<br>2. Indicador visual de avance curricular (barra de progreso).<br>3. Tiempo de carga no debe exceder los 5 segundos.<br>4. Interfaz responsiva para dispositivos móviles.<br>5. Diferenciación visual entre materias aprobadas y reprobadas.                                                                                                                                                                                                                                                          |
| **Suposiciones**              | 1. Se asume que el sistema tiene registrado el plan de estudios de cada carrera.<br>2. Se asume que cada materia tiene créditos asignados.<br>3. Se asume que las calificaciones de semestres anteriores están cerradas y validadas.<br>4. Se asume que el alumno está asociado a un plan de estudios específico.<br>5. Se asume que la descarga de historial en PDF no es un requerimiento confirmado.                                                                                                                                                              |
